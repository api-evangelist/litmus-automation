# Litmus API

> AI-friendly documentation for Litmus Edge, Litmus Edge Manager, and Litmus Unify. Static markdown - safe to fetch any single file in isolation. Total 2,004 endpoints across the three products.

## Entry points

- [Root router](https://api.litmus.io/agents.md): start here for any task
- [MCP Server](https://api.litmus.io/mcp-agents.md): tool-call layer (no code)
- [litmus-cli](https://api.litmus.io/cli.md): standalone CLI, the preferred method for agentic tasks
- [CLI and SDKs guide](https://api.litmus.io/sdk-agents.md): litmus-cli plus the Python SDK; Go and Rust SDKs in the works

## Products

- [Litmus Edge router](https://api.litmus.io/le/agents.md): industrial edge data platform, 871 endpoints in 4.0.x
- [Litmus Edge Manager router](https://api.litmus.io/lem/agents.md): centralized edge management, 304 endpoints in 2.31.x
- [Litmus Unify router](https://api.litmus.io/luns/agents.md): MQTT-based Unified Namespace, 46 endpoints

## Reference

- [Environment variables](https://api.litmus.io/reference/variables.md): every `{{variable}}`, split into set-once configuration and captured-at-runtime IDs
- [DeviceHub / DataHub message format](https://api.litmus.io/reference/devicehub-message-format.md): the flat JSON shape a tag value flows as (value, tagName, deviceID, datatype, ...), with a JSONata cheatsheet
- [Analytics processors (LE 4.0.x)](https://api.litmus.io/reference/analytics-processors.md): 56-processor catalog with description, config params, and required wire definitions per processor
- [LE changelog 3.16.x to 4.0.x](https://api.litmus.io/reference/changelog-le.md): GraphQL migrations (Analytics, Integrations), Digital Twin parameters, CloudSync, templates API
- [LEM changelog 2.26.x to 2.31.x](https://api.litmus.io/reference/changelog-lem.md): added/deprecated/removed endpoints with full operation list
